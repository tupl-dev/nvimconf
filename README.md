# Neovim Config
Configuration for `nvim`.

## Usage
Linux:
```sh
git clone https://github.com/tupl-dev/nvimconf
cd nvimconf && /bin/sh init.sh
cd .. && rm -rf nvimconf
```

Windows:
```pwsh
git clone https://github.com/tupl-dev/nvimconf
.\nvimconf\init.ps1
Remove-Item -Force -Recurse .\nvimconf\
```
